# Referenz: Briefing-Raster

> Raster für `briefing`. Struktur für Gesprächsvorbereitung bei Veranstaltungen, Interviews und Auftritten. Fiktive Beispiele.

## Aufbau

| Feld | Inhalt | Quelle |
|---|---|---|
| Anlass | Was, wann, wo, mit wem | Terminangabe |
| Format | Pressekonferenz, Interview, Podium, Statement | Einladung |

| Auftretende Person | Name, Funktion | Zuständigkeitsliste |
| Ziel | Ein Satz: was soll hängen bleiben | Presseleitung |
| Kernbotschaften | Drei, priorisiert | freigegebene Positionen |
| Zielgruppe | Wer hört zu | Einladung |
| Erwartbare Fragen | Hypothesen, nach Kategorien | Anlass und bereitgestellter Kontext; keine Antwortfreigabe |
| Antwortbausteine | nur falls einschlägige Position ausdrücklich freigegeben; Quelle, Stand und Freigabestatus nennen | freigegebene Position mit Fundstelle |
| Heikle Fragen | nicht ad hoc beantworten | Risikokriterien |
| Grenzen | was nicht gesagt wird | Presseleitung |
| Nachbereitung | Folgefragen, Kontakte | — |

## Fragenkategorien

| Kategorie | Beispielfrage |
|---|---|
| Fakten | „Wie hoch ist die Förderung?" |
| Kritik | „Warum erst jetzt?" |
| Vergleich | „Wie steht die [HOCHSCHULNAME] im Vergleich zu anderen?" |
| Zukunft | „Was kommt nach 2030?" |
| Haltung | „Was sagen Sie zur Kritik von Verbandsseite?" |
| Persönlich | „Wie fühlen Sie sich angesichts …?" |

## Antwortbaustein-Aufbau

1. **Brücke**: kurze Aufnahme der Frage
2. **Kernbotschaft**: die freigegebene Aussage
3. **Beleg**: eine Zahl oder ein Fakt
4. **Abschluss**: ein Satz, der die Kernaussage schließt

Kein Baustein länger als vier Sätze.

## Regeln für heikle Fragen

- Immer als „nicht ad hoc" markieren, wenn keine freigegebene Position vorliegt
- Rolle benennen, die antworten darf (Leitung, Justiziariat)
- Keine Spontanantwort, auch nicht „off the record"
- Kein „kein Kommentar" ohne Alternative — immer auf Kontaktweg verweisen

## Nicht im Briefing

- Krisenstatements (eigene Freigabekette)
- Rechtsberatung
- Personalthemen im Einzelfall
